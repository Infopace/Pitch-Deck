# Mint (iPreneur)

This repository contains the Mint AI pitch-deck product and related design/research artifacts. The application source lives in [`ipreneur/`](ipreneur/).

**Internal documentation:** start with the [product and architecture report](ipreneur/docs/product-and-architecture-report.md), then use the [documentation index](ipreneur/docs/README.md) to find API, data, pipeline, frontend, deployment, billing, security, and testing references.

The root also contains historical prototypes, exported assets, and design references. These are not necessarily part of the live application. The repository docs distinguish active code paths from legacy configs; check them before using files outside `ipreneur/` as product behavior.

## Quick local start

See [ipreneur/README.md](ipreneur/README.md) for local frontend/backend setup and [ipreneur/docs/environment-variables.md](ipreneur/docs/environment-variables.md) for configuration. Never commit populated `.env` files or secret-bearing deployment manifests.
